🔐 Gerador de Senha para Banco de Dados

Senhas fortes geradas com crypto.getRandomValues no seu navegador. Nada é enviado para servidor nenhum.

    Opções

    Tamanho

    O modo seguro usa só os símbolos e evita caracteres que quebram connection strings, URLs, SQL e shell (' " ` \ / @ : ; % & ? # = + $ e espaço).

    Algumas ferramentas e scripts tratam mal senhas que começam com número ou símbolo.

    Requisitos que a senha atende

    Sempre inclui pelo menos um caractere de cada tipo marcado. Com as opções padrão atende à política de complexidade do Azure SQL / SQL Server (8–128 caracteres, 3 de 4 categorias), Azure Database for PostgreSQL/MySQL, Oracle e afins. Guarde a senha num cofre como o Azure Key Vault — nunca no código.
